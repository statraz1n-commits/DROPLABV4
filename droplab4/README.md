# DROPLAB 4.0 — симулятор кейсов CS2

Полный сайт на Node.js 22.13+ с виртуальными скинами/кредитами, профилем, официальным Steam OpenID, инвентарём, апгрейдером, контрактами и SQLite. **Все CR, монеты и предметы — игровые.** Нет реального пополнения, ставок, трейда, вывода в Steam или получения денег.

## Обновлено в 4.0

- **Экономика переработана для всех 68 кейсов.** Используются вероятности по диапазонам *цены предмета относительно стоимости открытия*, а не только по редкости окраски. У CR-кейсов стоимостью от 650 CR самый дешёвый возможный приз не ниже 40% цены кейса, шансы окупа порядка 20–35% (конкретный процент виден при открытии). Дешёвые кейсы значительно рискованнее. Средний виртуальный возврат по всем CR-кейсам ниже стоимости открытия. Проверки экономических ограничений в `tests/economy.mjs`.
- **Улучшенный апгрейдер:** исходные скины (до шести) + добавленные CR, выбор цели, множители и поиск по цене. Колесо теперь анимируется одной непрерывной кривой без обратного хода, ключевых «прыжков» или искусственного перекручивания. Плавный режим — **6,2 сек**, длинный — **10,5 сек** с длительным торможением. Результат всегда определяется криптографическим генератором на сервере до анимации, не зависит от её режима, состояния FPS или скорости компьютера.
- **Рулетка для каждого из 9 открываемых кейсов.** ×1, ×2, ×3, ×5, ×7, ×9 и «МАКС» (открытие столько, сколько позволяют игровые средства, максимум 9). У каждой прокрутки собственная полоса, маркер, анимация и результат. Списание и выдача всех призов выполняются атомарно на сервере.
- **Звуки** вращения и выпадения реализованы через Web Audio; в шапке можно их отключать.
- **Новый дизайн:** графитовый интерфейс с приглушённой сиреневой подсветкой, горизонтальное меню, более спокойные карточки и новый вид профиля. Это собственный дизайн, *не точная копия* CaseBattle.
- **Контракты:** обмен 3–10 своих скинов на один случайный предмет. Итог выдаётся сервером, попытки заносятся в SQLite. Успешный по стоимости обмен возможен примерно в 20% попыток, когда в каталоге есть подходящие предметы.
- **Профиль:** общее количество открытий, попыток и успехов апгрейдера, контракты, сумма всех полученных предметов, стоимость текущего инвентаря, лучший дроп, количество монет и автоматически вычисляемый самый открываемый кейс.
- **Монеты ✦:** начисляются за открытия обычных кейсов и успешные апгрейды; специальные кейсы за монеты. Полученные там виртуальные скины можно продать за CR и использовать в апгрейдере.
- **68 кейсов, 265 скинов.** Локальные авторские обложки включены в ZIP. При доступе к интернету сервер пытается загрузить изображения CS2-скинов с внешнего каталога; без сети отображаются локальные силуэты. Лента содержит настоящие записи игроков и **явно подписанные ботами** демонстрационные записи.

Сайт не включает платёжные системы, реальные турниры с призами, розыгрыши настоящих предметов и вывод в Steam. Название CaseBattle и механики отдельных площадок не копируются один в один.

## Локальный запуск

1. Установи Node.js **22.13 или новее**.
2. Распакуй ZIP, открой терминал в папке с `package.json`.
3. Запусти:

   ```bash
   npm install
   npm start
   ```
4. Перейди на **http://localhost:3000**. Можно войти гостем или настроить Steam OpenID для публичного домена.

Никаких внешних npm-зависимостей нет. В Node.js 22 `node:sqlite` может писать предупреждение `ExperimentalWarning` — это не ошибка. Проверка проекта: `npm run check && npm test`.

## Вход администратора `xtc`

Имя администратора в этом проекте по умолчанию **`xtc`**. Его можно заменить с помощью `ADMIN_USERNAME`. **Пароль не встроен в JS, ZIP или HTML**: публиковать постоянный админский пароль в коде небезопасно.

Создай `.env` (или задай эти параметры в Render → Environment):

```dotenv
PORT=3000
BASE_URL=http://localhost:3000
DB_PATH=./data/droplab.sqlite
SESSION_SECRET=ПОМЕСТИ_СЮДА_ДЛИННУЮ_СЛУЧАЙНУЮ_СТРОКУ_ОТ_32_СИМВОЛОВ
ADMIN_USERNAME=xtc
ADMIN_PASSWORD=ВСТАВЬ_СВОЙ_ПАРОЛЬ_ЗДЕСЬ
ADMIN_STEAM_IDS=
STEAM_WEB_API_KEY=
```

После сохранения настроек и перезапуска сервера: **Войти → Вход для администратора**. Пароль `dick123`, который ты указал в чате, слишком короткий для публичной админки, поэтому рекомендуем задать отдельный длинный уникальный пароль в `ADMIN_PASSWORD`. Если хочешь использовать именно его, вручную впиши его значение в приватную переменную окружения Render, **не в репозиторий**. После настройки аккаунт администратора доступен после каждого перезапуска и деплоя, пока сохраняются эти переменные. В админке можно начислять CR и ✦ игрокам, просматривать аккаунты и журнал начислений. Для Steam-админов можно добавить свой SteamID64 через `ADMIN_STEAM_IDS`.

Данные аккаунтов не содержат паролей Steam. Вход идёт через официальный `steamcommunity.com/openid/login`.

## Развёртывание на Render

- Создай Web Service из репозитория, выбери Node.js 22.13+.
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Environment:** `BASE_URL=https://<твой-домен>.onrender.com`, `SESSION_SECRET`, `ADMIN_USERNAME=xtc`, `ADMIN_PASSWORD`, опционально `ADMIN_STEAM_IDS` и `STEAM_WEB_API_KEY`.
- Для постоянной SQLite-базы при деплое необходим **persistent disk** с `DB_PATH=/var/data/droplab.sqlite`; это может потребовать платный тариф. **На бесплатном Render локальная SQLite не защищена от потери данных при перезапуске/пересоздании инстанса**. Настройка в `render.yaml` рассчитана на дисковое сохранение.
- На статический Netlify ZIP просто загрузить нельзя: нужен сервер Node.js.

## Обновление с 1.0–3.0

1. **Сделай резервную копию SQLite**. Останови сервер перед копированием или создай согласованный SQLite-бэкап (учти файлы `-wal`/`-shm`).
2. Замени файлы программы на v4, **не перезаписывая** своё хранилище с базой.
3. Перезапусти `npm start`. Дополнительная таблица `contracts` создастся автоматически; существующие аккаунты, инвентарь и CR сохранятся.
4. Теперь новые открытия используют изменённые таблицы шансов. Уже выданные скины и их цены не изменяются.

## Дополнительные детали

- Шанс апгрейда: `max(0.001%, min(75%, 85% × (стоимость исходных вещей + дополнительные CR) / стоимость цели))`.
- У монетных кейсов стоимость открытия в ✦, стоимость приза в CR: это **разные валюты**, их нельзя непосредственно сравнивать как финансовую окупаемость.
- Цены и проценты — вымышленные значения внутри симулятора, не курсы реального рынка CS2. `crypto.randomInt` используется только на сервере.
- Ножи/скины — виртуальные записи в SQLite. Нет Steam Trade URL, передачи вещей и реального заработка. Арты CS2 принадлежат правообладателям. Неофициальный фанатский проект не связан с Valve, Steam, CaseBattle или упоминаемыми стримерами.
